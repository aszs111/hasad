# حصاد — ملفات تيليجرام على جوالك 📚

تطبيق أندرويد (Kotlin + Jetpack Compose) يعطيه رابط قناة تيليجرام، فيجمع ملفاتها على جوالك:
PDF، وورد، إكسل، كتب إلكترونية، صوتيات، بصمات، صور، فيديو.

## المزايا
- **افحص قبل التنزيل**: عدد الملفات وحجمها ومن أي سنة، ومقسّمة حسب النوع.
- **تختار وش تنزّل**: PDF ووورد وإكسل مختارة افتراضياً، والبرامج (apk, exe…) ما تنزل أبداً.
- **يسمّيها صح**: إذا اسم الملف عام (file_123.pdf) يسمّيه من أول سطر في وصف الرسالة.
- **يرتّبها**: مجلد للقناة › مجلد لكل قسم (من هاشتاقات القناة) › مجلد لكل سنة.
- **يكمّل لحاله**: التنزيل يشتغل بالخلفية ولو سكّرت التطبيق، ويحدّث القنوات كل يوم.
- **ما يرجّع المحذوف**: الملف اللي حذفته من المجلد ما ينزل مرة ثانية إلا إذا طلبت.
- **مكتبة**: بحث بالاسم أو الوصف مع تظليل الكلمة، أقسام، مفضلة، ورفوف خاصة.
- عربي/إنجليزي، روابط عامة وخاصة ورابط منشور، ومشاركة الرابط من تيليجرام مباشرة للتطبيق.
- القنوات اللي صاحبها مانع الحفظ يوضّحها ولا ينزّل منها.

الملفات تنحفظ افتراضياً في: `التنزيلات/حصاد/…` (تقدر تغيّره لأي مجلد).

## البناء (بدون كمبيوتر — عن طريق GitHub)
1. ارفع المشروع لمستودع جديد في GitHub (فرع `main`).
2. البناء يشتغل تلقائياً من تبويب **Actions**، وبعد ~10 دقائق يطلع ملف APK في صفحة **Releases**.
3. نزّل الـAPK على جوالك وثبّته.

### مفاتيح تيليجرام (مرة وحدة)
التطبيق يقرأ القنوات بحسابك عن طريق مكتبة تيليجرام الرسمية (TDLib)، وهذي تحتاج مفتاحين:
1. ادخل https://my.telegram.org بحسابك ← **API development tools** ← أنشئ تطبيق.
2. انسخ `api_id` و `api_hash`.
3. إما تكتبهم في التطبيق أول ما تفتحه، أو تحطهم في GitHub:
   Settings ← Secrets and variables ← Actions ← أضف `TG_API_ID` و `TG_API_HASH`.

## تقنياً
- مكتبة TDLib الجاهزة تُجلب وقت البناء من مستودع Telegram X (`TGX-Android/tdlib`) — مثبّتة على إصدار محدد.
- `scripts/fetch-tdlib.sh` ينسخ ملفات Java والمكتبات الأصلية داخل المشروع.
- قاعدة بيانات SQLite للقنوات والملفات والرفوف، و WorkManager للتنزيل والتحديث اليومي.
- مفتاح التوقيع `app/hasad.keystore` ثابت عشان التحديثات تنزل فوق القديم بدون حذف.
